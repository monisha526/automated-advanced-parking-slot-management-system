📊 Analytics & Tracking

📈 Firebase Analytics

Track user behavior, bookings, payments, and exits. Auto-enabled once Firebase is configured.

Tracked Events:

  • parking_booked - When a booking is created
  • payment_completed - When payment is processed
  • parking_exit - When vehicle exits lot
  • late_fee_charged - When overstay fine is applied
  • email_sent - When notification email sent
  • feedback_submitted - When customer submits rating

📋 Audit Logging

🔐 User Action Logging

Automatic logging of all user actions for security and compliance.

Logged Actions:

  • Payment attempts
  • Booking creation
  • Slot exits
  • Admin dashboard access
  • Data modifications
  • Error occurrences
All logs are stored in Firestore collection: audit_logs

🐛 Error Tracking

⚠️ Centralized Error Reporting

Automatically track and report errors for debugging and monitoring.

Features:

  • Captures error messages and stack traces
  • Records browser and user information
  • Stores in Firestore collection: error_logs
  • Includes context information (URL, user email, timestamp)
  • Helps identify patterns and recurring issues
